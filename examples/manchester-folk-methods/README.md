# Manchester Folk-Methods Dataset (Provenance Materials)

This folder holds the provenance and supporting materials for the University of Manchester Figshare dataset behind the ACE guide sample:

Fflur, Myfanwy (2026). Identifying "Folk-Methods" Employed With Fitness Applications By Users With Chronic Mobility Issues To Improve Application Design - Survey Results, Interview Transcripts and Codebook. University of Manchester. Dataset. https://doi.org/10.48420/31900453.v1

The deposited files are provided under the Creative Commons Attribution 4.0 International licence (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/

## Contents

- `codebook/` - the deposited codebook PDF.
- `surveys/` - the deposited survey files.
- `metadata/figshare-article-31900453.json` - Figshare API metadata captured at download time.
- `metadata/manifest.tsv` - file sizes, MD5 checksums, expected MD5 checksums, and Figshare download URLs for the included deposited files.
- `ATTRIBUTION.md` - attribution and reuse notes to keep with any redistributed copy.

The deposited interview transcripts are not redistributed in this folder; they duplicate the transcripts already shipped with the importable sample in `../ace-guide-manchester-folk-methods/`.

## Importable Sample

Nothing in this folder is an ACE import file. For the importable sample - 19 sources plus a codebook CSV ready to load into ACE - use `examples/ace-guide-manchester-folk-methods/`, described on the website's "Try the sample data" page.

## Provenance

The deposited files were downloaded from Figshare on 2026-06-18 and verified against the file sizes and MD5 checksums published by the Figshare API. The files are unchanged apart from being placed into subfolders by file type; `metadata/manifest.tsv` records the checksums.
