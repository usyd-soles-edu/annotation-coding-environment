Codebook editing (on the coding page)

⌥ + →
Move code into the folder above
⌥ + ⇧ + →
Wrap two root codes into a new folder
⌥ + ←
Move code out of folder, back to root
⌘/Ctrl + X
Cut focused code
⌘/Ctrl + V
Paste cut code into focused folder/row
Shift + F10 / Menu
Open actions for the focused code or folder
⇧ + Enter (in filter)
Create new folder at root
F2
Rename focused code or folder
⌫
Delete focused code or folder (Z to undo)
Esc
Codebook → source · cancel cut · clear filter
